## Escenario Seleccionado

## Descripción del Proyecto

El presente proyecto fue desarrollado como parte del Trabajo Práctico N.º 2 de Organización Empresarial.

El objetivo principal consiste en aplicar herramientas de gestión colaborativa, control de versiones y organización de proyectos utilizando Git, GitHub, Jira y Google Colab.

El proyecto implementa un análisis básico de ventas mediante Python, permitiendo calcular métricas comerciales y generar visualizaciones gráficas a partir de un dataset en formato CSV.

## Tecnologías Utilizadas

- Python
- Pandas
- Matplotlib
- Git
- GitHub
- Jira
- Google Colab

## Funcionalidades Implementadas

- Importación de dataset CSV.
- Cálculo de ventas totales.
- Identificación del producto más vendido.
- Generación de ventas mensuales.
- Creación de gráfico estadístico.
- Exportación de resultados.

## Ejecución del Proyecto

1. Clonar el repositorio.

2. Acceder a la carpeta scripts.

3. Ejecutar el archivo analisis_ventas.py.

## Resultados Generados

El script genera:

- gráfico de ventas
